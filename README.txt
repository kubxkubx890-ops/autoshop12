AutoSklep - mod kliencki Fabric dla Minecraft 1.21.4

SPRZEDAZ: /sklep -> kompas (lewy) -> czerwona welna (lewy) -> miedz (shift + prawy) -> ESC.
  - gdy kazdy niechroniony slot to miedz (od razu),
  - oraz co X sekund (domyslnie 120), niezaleznie od zapelnienia.
  - jesli sprzedaz sie nie uda (miedzi nie ubylo): ESC i ponowna proba (max 5x).
WYRZUT: co X sekund (domyslnie 60) otwiera ekwipunek i wyrzuca wszystko poza miedzia
  i slotami zaznaczonymi jako chronione. Domyslnie WYLACZONY.

KLAWISZE
G  - okno ustawien (komenda, czasy, wyrzut, chronione sloty)
H  - wlacz/wylacz
/autosklep [start|stop|gui|status|sprzedaj|wyrzuc|cmd <komenda>]

Mod wylacza pauzowanie gry po utracie fokusu okna, wiec dziala przy zminimalizowanej grze.
UWAGA: sprawdz regulamin serwera - automatyzacja moze byc zabroniona.
